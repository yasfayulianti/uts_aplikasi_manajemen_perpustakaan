# Aplikasi Manajemen Perpustakaan

Aplikasi Manajemen Perpustakaan merupakan project berbasis **Python** yang dibuat untuk membantu proses pengelolaan perpustakaan, mulai dari pengelolaan data buku, anggota, hingga transaksi peminjaman.

## Tujuan Project

Project ini dibuat untuk menerapkan konsep Object-Oriented Programming (OOP) dalam membangun sistem manajemen perpustakaan yang terstruktur dan mudah dikelola.

## Fitur Aplikasi

- Pengelolaan data buku.
- Pengelompokan buku fiksi dan nonfiksi.
- Pengelolaan data anggota perpustakaan.
- Pengajuan peminjaman buku.
- Persetujuan dan penolakan peminjaman oleh admin.
- Pengelolaan status peminjaman dan pengembalian.
- Perhitungan denda keterlambatan.

## Teknologi yang Digunakan

- Python
- Visual Studio Code
- Git & GitHub

## Cara Menjalankan Aplikasi

1. Clone repository:

   ```bash
   git clone https://github.com/yasfayulianti/uts_aplikasi_manajemen_perpustakaan.git
   ```

2. Masuk ke folder project:

   ```bash
   cd uts_aplikasi_manajemen_perpustakaan
   ```

3. Jalankan aplikasi:

   ```bash
   python main.py
   ```
